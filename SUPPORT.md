# Support

Start with [Using FPGAI](docs/USING_FPGAI.md), the [FAQ](docs/FAQ.md) and [Supported features](docs/SUPPORTED_FEATURES.md).

For a reproducible bug, open a GitHub issue including the source revision, Python version, operating system, commands, expected behavior and sanitized error output. Feature proposals should describe the relevant compiler contract. Never post confidential weights, datasets, credentials or vendor artifacts.

Source permissions: [Licensing](docs/LICENSE_DECISION.md). Vulnerability reports: [Security](SECURITY.md). No fixed support response time is guaranteed.
