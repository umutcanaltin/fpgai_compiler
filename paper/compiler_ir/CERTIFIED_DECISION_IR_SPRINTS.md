## Machine-checkable action contract, v1

Current implementation is \`model_ir/decision_interface.py\`. It does NOT add a Gym dependency, change original \`compile_cst\` or train a GNN.

- \`create_state(model, overrides, limits, policy, row_block)\` rejects a complete proposal that the actual compiler cannot source-lower.
- \`transition(state, action)\` constructs an immutable candidate and recompiles it using \`resolve\` + \`compile_cst\`. It returns \`Accepted(new_state, certificate)\` or \`Rejected(original_state, reason, counterexample)\`. A source/contract exception is not repaired or silently clamped.
- \`action_mask(state, candidates)\` uses precisely that same transition path, so a true bit means source-level compiler admissibility **for the supplied finite actions only**. This is not a hardware resource/timing mask.
- \`graph_observation(state)\` emits topologically canonical operator/tensor/edge features without raw weights or tested-native QoR. Phi probes are spatial coordinate assignments, **not** per-value availability or timing proofs.
- Proof/evidence labels are **E0 compiler legality + E1 source generated**, not E1 numerical execution unless the separate host validator ran, never physical FPGA.
- The \`DecisionState\` supports complete assignments only. No arbitrary \`STOP\`, partial state or RL episode semantics exists yet. These belong to future sprints and must not be inferred.

## Scientific R1–R6 study matrix

1. **R1 exact finite masks:** complete tiny candidate catalogs; compare production source-admission decisions with a separately implemented bounded restricted oracle, report all false legal/illegal decisions, source SHA, counterexamples. New \`cst_decision_campaign\` covers a restricted initial subset; this is **not** the full Phi-aware oracle.
2. **R2 Phi causality:** hold Functional/target/layout/action fixed, mutate Phi in supported legal ways, and see per-element completion and consumer read legality **change because of computed obligations, not different hashes**. This is the central *missing* novelty experiment.
3. **R3 variable-size/renaming invariance:** compare public observations/actions across syntactically renamed but mathematically equivalent graphs, variable depths and widths. No model-weight leakage. Compiler state hashes can differ by names (provenance) while public GNN features match.
4. **R4 agent independence:** replay the same edit list from a human, fixed-seed random and heuristic policy through one interface; no special legal-mask implementation for agents. Measure certified designs, actual GCC source validity and checking overhead, **not HLS speedup**.
5. **R5 hardware QoR (optional to first IR paper):** original source-qualified Vitis CSim/CSynth on matched legal actions with resource limits and failing cases; no requested clock equals achieved Fmax.
6. **R6 trained RL later:** shared GNN on unseen networks, ablations operator graph vs contract graph vs legal mask under equal HLS budgets; source-attested reward and confidence intervals across seeds. Excluded from compiler paper until explicitly unfrozen.

## Stop rules

- An E0 source mask is **not** a proven resource/timing feasible action.
- A local Phi SHA or spatial-coordinate probe is **not** element-completion/read-after-write proof.
- Whole-row one-consumer verification cannot be used to claim arbitrary DAG/fan-out compositional correctness.
- A trained-policy reward increase alone cannot establish compiler IR novelty; original RL is frozen.
- Allo/CompilerGym/RL4ReAl/ST-Flow already span important IR/search/RL mechanisms. An equivalent certificate/transition interface in prior art invalidates unqualified firstness.
- A new experiment plan/CI test is not a scientific finding until it is executed against a source-pinned code revision.
